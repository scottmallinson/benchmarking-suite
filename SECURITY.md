# Security Policy

## Supported versions

Only the latest release (or `main`, if unreleased) receives security fixes.

## Reporting a vulnerability

**Do not open a public issue.** Report privately using either:

- GitHub's [private vulnerability reporting](../../security/advisories/new)
- Email: scott@scottmallinson.com

Please include a description, reproduction steps, and the impact you foresee.
You can expect an acknowledgement within 3 working days and a status update
within 10. We will credit reporters who wish to be named once a fix is released.
